SELF-HOSTED PATH
Run Qev on your machine
Choose your system · copy the commands

        
You need Git, Python, an authorized Qev checkpoint and its matching Qwen base. The checkpoint folder must contain model.json, temperature.json, head.pt and the adapter folder. Model files are not supplied here. Setup downloads dependencies; inference uses local files.

        

1 · Set up
git clone https://github.com/ba-research/try-qev.git
cd try-qev
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r local/requirements.txt
2 · Set your base path. Copy the entire checkpoint folder. In the copy’s model.json, set model_id to the absolute path of the matching local Qwen base. Keep its other fields and files intact.
3 · Start Qev
python local/try_qev.py --checkpoint "/absolute/path/to/YOUR_CHECKPOINT_COPY"
