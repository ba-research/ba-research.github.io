# BA Research

Independent AI research from Calgary, Alberta. The website is static and uses no build step or external fonts.

## Try Qev

Qev is an experimental decision-model family. Instant browser inference is not available yet, and this repository does not host model weights. Choose an existing way to explore:

- **Run it locally:** [local setup instructions](local/README.md) explain prerequisites and how to run the playground after obtaining the approved matching model files.
- **Explore examples:** [open the Colab notebook template](https://colab.research.google.com/github/ba-research/ba-research.github.io/blob/main/notebooks/ba_research_qev_enterprise_template.ipynb). It uses fictional energy and enterprise scenarios; a provisioned cloud runtime and model files are required for inference.
- **Review the models:** [Qev model cards on Hugging Face](https://huggingface.co/ba-research) describe available artifacts and limitations.
- **Inspect the gateway research:** [Shunt on GitHub](https://github.com/stancsz/shunt).

Qev outputs require independent validation and qualified human review. Illustrative scenarios are not operational advice; do not rely on the model alone for safety-critical or other consequential decisions.
