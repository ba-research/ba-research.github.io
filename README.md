# BA Research website

Static GitHub Pages site for BA Research, an independent Calgary lab focused on pragmatic AI research and LoRA training for edge, self-hosted and enterprise deployment.

[Try Qev](https://ba-research.github.io/#try) presents recorded research results. The [Try Qev repository](https://github.com/ba-research/try-qev) contains the local demo and Colab template. Neither repository includes model weights; direct browser inference and hosted Colab inference are not yet available.
