# BA Research

Website and local decision-model experiments for BA Research, an independent AI research lab in Calgary, Alberta. The website is static and uses no build step or external fonts.

- Open [the local playground instructions](local/README.md) for offline inference after setup and approved model acquisition.
- The [notebook template](notebooks/ba_research_qev_enterprise_template.ipynb) contains fictional energy and enterprise examples. Colab is a cloud service; its environment must be provisioned before real inference.
- Explore [model cards](https://huggingface.co/ba-research) and [Shunt](https://github.com/stancsz/shunt).

This repository contains no model weights. Qev is experimental; its outputs require independent validation and qualified human review. Illustrative scenarios are not operational advice.
